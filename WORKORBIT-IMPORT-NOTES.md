# WorkOrbit source bundle

This archive reorganizes the supplied source tree into:
- `frontend/`: existing Next.js frontend
- `backend/`: existing NestJS backend (not yet migrated to Next.js)
- `contract/`: existing Soroban contract source
- `docs/`: project documentation
- `.github/`: existing workflows and templates

## Important status

This is a source-transfer bundle, not a completed Next.js full-stack migration. The backend is still NestJS and will need to be migrated before the intended architecture is complete. Review CI paths and deployment configuration after uploading.

The original `LICENSE` and relevant upstream notices are retained. Do not remove copyright or license notices required by the applicable license.

## Upload

Extract this ZIP, copy its contents into a local clone of `https://github.com/samkiell/WorkOrbit`, inspect the changes, then commit and push from your machine.
