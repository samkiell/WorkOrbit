# WorkOrbit

> A Stellar-powered freelance marketplace for escrow, milestones, and on-chain payouts.

WorkOrbit is a maintained continuation of the Stellance freelance marketplace project, focused on making decentralized freelance work practical through Stellar and Soroban.

## Project Status

This repository is being prepared as the maintainer workspace for ongoing development. The current upstream implementation already includes a Soroban escrow contract, a NestJS backend, and a Next.js frontend.

Planned work will prioritize:

- Completing the freelance marketplace experience
- Stellar wallet integration with Freighter
- End-to-end Soroban escrow integration
- Milestone-based payments and dispute handling
- Testnet deployment and testing
- Documentation, contributor experience, and CI

## Technology

- Next.js 16 + React 19
- Tailwind CSS 4
- NestJS 11
- Prisma + PostgreSQL
- Stellar + Horizon
- Soroban smart contracts
- Rust
- Freighter wallet
